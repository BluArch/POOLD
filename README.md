# Working MVP (October 29, 2026)

The Expo / React Native app, Node API and MySQL implementation are now in this repository. Start with [setup instructions](Documentation/implementation/SETUP.md), [API documentation](Documentation/implementation/API.md), and [verification evidence](Documentation/implementation/VERIFICATION.md). The implementation follows phases A–E of [the MVP plan](Documentation/implementation/MVP_PLAN.md), retains the approved neutral three-tab design, and excludes all payment-related features.

Local preview: `npm run dev` after setup.

Live app: **[poold.onrender.com](https://poold.onrender.com)**. Hosted on [Render Free + Aiven MySQL Free](Documentation/implementation/HOSTING.md), with Brevo verification email configured. Free hosting sleeps when idle; the first request can take about a minute.
